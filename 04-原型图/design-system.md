# 设计系统 · 快递驿站出入库与滞留预警系统

> 视觉方向：运动钴蓝（专业业务系统）。核心目标是数据可读性与操作效率，不做装饰性光效、悬浮球与大幅插画。
> 本文件是 build 阶段 1:1 复刻的依据，颜色、字号、间距一律取此处的值。

## 3. 布局与栅格

- 桌面端：左侧菜单 **220px**（折叠后 56px 只留图标）、顶部栏 **56px**、内容区自适应。
- 内容区外边距 **24px**；卡片间距 **14–16px**。
- 看板单行 6 个 KPI，图表 3 列 × 2 行，行高 262px，**1440×900 一屏无滚动**。
- 表格容器 `overflow-x:auto`，表头不写死宽度，按内容自适应最小宽度；编号/状态/日期/操作列 `nowrap`。
- 表单：标签宽 96–120px，单列输入 360–520px；搜索下拉 180–240px。
- 低于 768px：侧栏转抽屉，筛选折成底部面板，表格转信息卡片（只留编号/状态/时间/负责人）。

## 7. 业务状态与视觉映射

主流程：`到站入库 → 货架分配 → 待取通知 → 身份核验 → 出库完成 / 异常处理`

| 状态 | 标签色 | 说明 |
|---|---|---|
| 待上架 | 警告 | 已入库未分配货架 |
| 在库 | 进行 | 已上架，未通知或已通知 |
| 已通知 | 进行 | 已生成待取通知记录 |
| 已取件 | 成功 | 终态，修改需负责人审批 |
| 待退回 | 危险 | 超阈值或拒收，待与快递员交接 |
| 已退件 | 中性 | 终态 |
| 异常件 | 危险 | 破损/错件/丢失等，需审核关闭 |

滞留分级（按在库天数）：正常 ≤3 天（中性）、即将滞留 4–5 天（警告）、已滞留 6–9 天（危险）、待退回 ≥10 天（危险 + 加粗）。

## 9. 数据口径（写 SQL 时照用）

- 站点：南湖大学城站（ST-001），营业 08:00–21:30，负责人周敏。
- 货架：A 区小件 8 个（容量 120）、B 区中件 6 个（80）、C 区大件 4 个（40）、D 区异形贵重 2 个（24），总容量 1,648。
- 快递公司：顺丰速运 SF、京东物流 JD、中通快递 ZTO、圆通速递 YTO、韵达快递 YD、极兔速递 JT。
- 件型：小件 S（≤30cm）、中件 M（30–60cm）、大件 L（>60cm）、异形件 X。
- 创新点权重（合计 100）：包裹尺寸 20、货架容量 25、快递公司分区 15、入库时长 25、通知次数 10、特殊件标记 5。
- 等级：优选 ≥85 / 可用 70–84 / 受限 <70。
- 看板基线：在库 1,264 件、今日入库 428、今日出库 386、滞留 87、异常 6、占用率 77%。
