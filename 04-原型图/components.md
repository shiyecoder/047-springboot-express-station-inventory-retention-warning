# 组件规范 · 快递驿站出入库与滞留预警系统

> 与 `design/mock.css` 一一对应。build 阶段用 Element Plus 实现时，按此处尺寸覆写变量，不要另起一套。
> 所有尺寸单位为 px，颜色取 `design-system.md` 的变量。

## 按钮

| 类型 | 高度 | 内边距 | 底色 | 边框 | 文字 | 场景 |
|---|---|---|---|---|---|---|
| 主按钮 `.btn.primary` | 34 | 7 14 | `#0F3B5D` | 同底色 | `#fff` | 每屏 1 个，主流程动作 |
| 次按钮 `.btn` | 34 | 7 14 | `#fff` | `#DCE5EC` | `#16232E` | 导出、重置、取消 |
| 幽灵 `.btn.ghost` | 34 | 7 14 | `#EAF2F8` | `#C3D5E2` | `#0F3B5D` | 保存草稿、暂存 |
| 危险 `.btn.danger` | 34 | 7 14 | `#fff` | `#E7C4C7` | `#B22B31` | 批量退件、删除 |
| 小号 `.btn.sm` | 28 | 4 10 | 同上 | 同上 | 12px | 表格行内操作 |

规则：表格行内最多「查看 + 2 个高频操作」，其余收进「更多」；行内操作文字链接用强调色 `#245A7A`，不加按钮边框；危险操作红色描边 + 二次确认弹窗。

## 表单

- 输入框/下拉：高 34，圆角 6，边框 `#DCE5EC`，聚焦时边框 `#2878B5` + 外发光 `0 0 0 3px rgba(40,120,181,.14)`。
- 表单项：标签右对齐，宽 96（抽屉内）/ 110（整页表单）；控件与标签间距 10。
- 两列表单用 `.fgrid`（`grid-template-columns:repeat(2,1fr)`，列间距 20，行间距 12）；跨列项 `.full`。
- 下拉宽度：搜索栏 180–240；表单内随容器宽度。
- 文本域行高 20，`resize:vertical`，最小 2 行。
- 校验：必填项标签后加 `*`（强调色）；错误提示在控件下方 12px 红字；保存前统一校验，不允许逐字段弹出。
- 关闭有未保存内容的抽屉/页面时，弹「放弃编辑 / 继续编辑」确认。

## 表格

- 表头：背景 `#F7FAFD`，字色 `#5C6B78`，字号 13，字重 500，下边框 `#DCE5EC`，内边距 9 12。
- 单元格：内边距 9 12，下边框 `#EDF3F8`，行悬浮背景 `#F8FBFD`。
- 表头不设固定宽度；编号、状态、日期、操作列 `white-space:nowrap`；数字列右对齐 + `tabular-nums`。
- 空状态：留白 36px，居中说明「当前筛选条件下无记录，清空筛选或新建入库记录」。
- 分页：右下角，左侧「共 N 条 · 每页 [10/20/50] 条」，右侧「上一页 / 页码 / 下一页」；切换筛选后回到第 1 页。

## 卡片

- 白底，1px 边框 `#DCE5EC`，圆角 8，内边距 16 18。
- 标题 16/600，与内容间距 10；右上角可放说明文字（12px，次要色）或标签。
- 卡片内不嵌套卡片；需要分组时用 1px 分隔线 + 12px 间距。

## 指标卡（KPI）

- 6 列网格，间距 12；内边距 12 14；圆角 8。
- 结构：标签（12px 次要色）→ 数值（26/34，600，`tabular-nums`）→ 说明（12px，上升 `#1F7653`，下降 `#B22B31`）。
- 数值后缀单位用小号（13px）紧跟，不换行。

## 摘要条 `.summary`

- 4 等分，白底 1px 边框，圆角 8，段间 1px 竖线分隔，段内内边距 11 16。
- 结构：标签 12px 次要色 / 值 17px 600。用于单据页顶部（交接总数、已扫、待扫、异常）。

## 标签

见 `design-system.md` 第 6 节。高度 19，圆角 4，内边距 1 7，字号 12，`white-space:nowrap`。
禁止只靠颜色传达状态：必须写中文（「已滞留」而不是只有红点）。

## 抽屉与弹窗

- 抽屉：右侧滑出，宽 520（表单）/ 720（含明细）；标题 15/600 + 右上关闭；底部固定操作条（高 56，右对齐，主按钮在右）。
- 抽屉内先显示单据摘要（编号、状态、责任人），再显示表单，避免审批人来回切页。
- 弹窗：宽 420（确认）/ 640（表单）；危险确认主按钮为红色。

## 图表

- 折线：`#0F3B5D` 主系列 + `#2878B5` 对比系列，线宽 2，末点实心圆 r=3；Y 轴 4 条网格线 `#EDF3F8`，轴标签 10px `#8A98A5`；X 轴标签过密时隔一个显示，最后一个右对齐。
- 横向条：条高 14，底槽 `#EDF3F8`，填充 `#2878B5`，左侧名称宽 78 右对齐，右侧数值宽 46。
- 竖向柱：最小可视高度 4%，柱宽上限 34，数值在柱顶 11px，分类标签在柱底。
- 环图：直径 132，内圈白底留 26，中心显示总数 + 单位；右侧图例每行「色块 + 名称 + 数值」。
- 6 个图表统一行高 262（1440×900 两行正好一屏），卡片内 `overflow:hidden`，图表容器 `flex:1;min-height:0`。
- 加载超过 300ms 显示骨架屏，禁止整页白屏。

## 图标

- 24×24 viewBox，线性描边 1.6，`stroke:currentColor`，尺寸 18。
- 图标集见 `design/icons.svg`：grid / tent / tree / map / box / truck / shield / clipboard / star / wallet / sun / users / calendar / check / clock / bell / search / plus / alert / chart / settings / user / file / photo / wrench / logout / chevron。
- 顶栏图标按钮 32×32，1px 边框，圆角 6，图标 18；**必须给 `svg` 显式宽高**，否则默认 300×150 溢出。

## 时间轴 `.timeline`

- 左侧 1px 竖线 `#DCE5EC`，节点圆点 9px 白底 + 2px 边框（进行 `#2878B5` / 完成 `#1F7653` / 异常 `#9A6B1F`）。
- 每条：事件名 13px + 说明 12px 次要色；节点间距 14。
- 事件不可由普通用户编辑；驳回、退回、人工调整必须带原因（≥5 字）。

## 上传

- 缩略图 132×96（圆角 6，1px 边框）；上传占位 104×104（虚线 `#C3D5E2`，背景 `#F7FAFD`）。
- 限制：JPG/PNG，单张 ≤5MB，显示上传进度；删除需确认。
- 只保存到项目 `/uploads/`，页面不得出现「填写图片 URL」的输入框。

## 货架可视

- 4 列网格，卡片内：编号（14/600）+ 状态标签 → 区域说明（12px）→ 占用条（高 8）→ 「已用/容量 位」+ 百分比。
- 占用条颜色：<90% `#2878B5`、90–99% `#C98A1E`、100% `#B22B31`；停用货架整卡虚线 + 灰底。
- 满载与停用必须有文字标签，不能只靠进度条颜色。

## 移动端（<768px）

- 卡片化列表：标题 13/600 + 两行说明 12px + 状态标签；卡片间距 10。
- 主操作按钮固定底部安全区，高 48，宽度 100%，不得遮挡分页与导航。
- 底部标签栏 64px，4 个入口（扫码入库 / 取件 / 消息 / 我的），当前项主色 + 加粗。
- 点击区不小于 44×44；沙箱扫码框高 120，虚线边框。
